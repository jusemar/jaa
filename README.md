# Jaaa

Super app web e mobile que reúne mensageria, delivery, empresas, profissionais e agendamento de serviços em um único ecossistema.

🌐 https://jaaa.com.br

## Sobre o projeto

O Jaaa é um produto desenvolvido de forma contínua, envolvendo planejamento, arquitetura, desenvolvimento, testes, correções e publicação em produção.

O projeto integra diferentes experiências em uma única plataforma, permitindo comunicação entre usuários, descoberta de empresas e profissionais, pedidos e agendamentos.

## Principais recursos

- Mensageria e conversas
- Perfis de usuários, empresas e profissionais
- Delivery, cardápios e pedidos
- Busca de empresas e profissionais
- Agendamento de serviços
- Gestão de disponibilidade
- Aplicação mobile
- Integrações com APIs e serviços externos

## Tecnologias

- React
- Next.js
- React Native
- TypeScript
- Node.js
- PostgreSQL
- APIs REST
- Git

## Desenvolvimento assistido por IA

Inteligência Artificial é utilizada como ferramenta de apoio durante diferentes etapas do desenvolvimento, incluindo planejamento, análise, implementação, testes, revisão de código e resolução de problemas.

## Status

Projeto em desenvolvimento contínuo, com aplicação web publicada em produção.
